# Howard Cheng — Personal Portfolio

I built this website to introduce myself as a software and web developer,
share my background, and highlight projects I have worked on.

## What I share

- My education, study-abroad experience, honors, and languages
- Selected projects, including VendorLink and SoloGo
- Links to my GitHub and LinkedIn profiles
- A future space for my art portfolio

## Technology

I built the site with Next.js, React, TypeScript, Tailwind CSS, and the
Next.js App Router. I use custom Eczar and Work Sans typography alongside
responsive layouts and reusable navigation and footer components.

## Website sections

- `/` — My introduction and featured biography
- `/about` — My education, experiences, honors, and languages
- `/projects` — My selected projects
- `/contact` — Ways to connect with me online
- `/art-portfolio` — My upcoming art portfolio

## Project structure

- `app/` — Pages, shared components, metadata, and global styles
- `public/` — Portrait, project screenshots, icons, and other website assets
